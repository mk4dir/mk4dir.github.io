Kubernetes Mimari

Konsept olarak Master(Control Plane) ve Node(Worker)’lardan oluşan bir mimariye sahiptir. Temelde uygulamalarımızı Docker ya da diğer konteyner teknolojileriyle containerized edip kubernetes’e teslim ediyoruz. Çalıştırma işlemini iste Master üzerinden Node’lara yaptırıyoruz. İşlemleri kısaca maddeler halinde yazarsak da,

  • Uygulamamızı geliştirdikten sonra bunu uygun bir şekilde bir docker image haline getiririz.
  • Sonrasında bir manifest dosyası oluştururuz. (Manifest dosyaları .yaml ya da .json uzantılı dosyalardır.)
  • Bu dosyayı Kubernetes API server’a göndeririz.

Kubernetes Bileşenleri

Master ve node’larda yer alan bileşenler aşağıdaki şekildedir.

Master Bileşenleri

1 - kube-apiserver : Kontrol ortamının frontend’i

2- etcd : Cluster’ın bilgisini tutan key-value datastore

3- kube-scheduler : Master node üzerinde yeni oluşturulmuş ve herhangi bir node’a atanmamış olan podları çalıştırmak için node belirler.

4- kube-controller-manager : Bazı kontrolleri çalıştırır. Bunlar:

  • Node Controller: Herhangi bir node down olduğu zaman bunu farketmekle yükümlüdür.
  • Replication Controller:
  • Endpoints Controller: Servisleri ve podları birbirine bağlar.
  • Service Accont & Token Controllers : yeni namespace için API access token sağlar.

Node Bileşenleri :

Kubelet : Her bir node üzerinde çalışan ajan. Podların düzgü çalışıp çalışmadığını kontrol eder.

Kube-proxy : nodeların haberleşmesi.

Container-Engine container’larin calismasi icin gerekli olan engine

CRI : Container Runtime Interface : docker

Minikube kurulumu için: VirtualBox kur. Kubectl kur https://kubernetes.io/docs/tasks/tools/install-kubectl/ .

Sonra da minikube kur. https://kubernetes.io/docs/tasks/tools/install-minikube/

Kubernetes Cluster kurulumu için:

KUBECTL

kubectl get pods / pod FOO: describes detailed information about all pods or a spesified pod foo

kubectl expose deplyment tomcat-deployment –type=NodePort : exposes a port (TCP or UDP) for a given deployment, pod, or other source

**kubectl port-forward tomcat-deployment-7317s8df-y6fsd89 5000:6000 ** Forwards one or more local ports to a port

kubectl attach tomcat-deployment-7317s8df-y6fsd89: Attaches to a process that is already running inside an existing container

kubectl exec -it tomcat-deployment-7317s8df-y6fsd89 bash Execute command in a container -t option will specify stdin is a TTY

**kubectl label pods: ** Updates the labels on a resource .

kubectl run hazelcast –image? hazel –port Run a particular image on the cluster
